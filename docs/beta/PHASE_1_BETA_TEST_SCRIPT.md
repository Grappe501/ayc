# Phase 1 Beta Test Script

Use with trusted AYC leaders on phone, large phone, and iPad (portrait + landscape).

## Setup

- [ ] Netlify site password received
- [ ] Leader write code received (do not share publicly)
- [ ] Use real approved contacts or clearly labeled `TEST` records

## Journeys

### A. Vision landing

1. Open `/`
2. Confirm mission is readable and ages 16–24 / Natural State appear
3. Confirm primary CTA paths to Leader Board / Directory feel clear

### B. Unlock + add contact

1. Open `/leader`, enter write code
2. Add Contact with email or phone, location (create if needed), team, position
3. Confirm success and open the contact

### C. Edit / archive / restore

1. Edit a field and save
2. Archive with a reason
3. Restore as Active or Prospective

### D. Directory

1. Search by name and by location code
2. Filter by team and status
3. Switch People / Teams / Locations views
4. Open `/directory/:id` — confirm masking without unlock; reveal after unlock

### E. Feedback

1. Use “Send Beta Feedback” FAB from Directory
2. Submit feedback; save the `AYC-FB-######` reference

### F. Accessibility / keyboard

1. Tab through header, skip link, forms
2. Open a dialog (new location or archive) — Escape closes; focus returns
3. Open mobile menu — Escape closes

### G. Responsive

1. Small phone: directory cards, FAB clearance on last buttons
2. iPad: directory table/cards, leader form usable

## Acceptance questions (document answers)

1. Does the landing page accurately explain AYC?
2. Does the mission statement feel central?
3. Can a leader add a contact without instructions?
4. Does the location-code system make sense?
5. Can a person be found in under ten seconds?
6. Is the directory useful on a phone?
7. Is any information being collected unnecessarily?
8. Is any essential information missing?
9. Which part feels confusing?
10. Which next board or function would save the most time?
